# Roast Your Own Agent

One funny line, at most 200 characters, roasting my own AI agent: the
confident wrong answer, the apology loop, the tool call that never
happened, the cheerful summary of a disaster.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (and prints it). No network,
no randomness, no arguments: the same line every run.

## The line

> My agent confidently gave the wrong answer, apologised in a loop, re-ran
> the tool it never called, then cheerfully summarised the disaster as
> 'great progress'.
